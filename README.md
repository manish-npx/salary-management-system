# Salary Management System

A clean, layered salary management tool for an organization-scale employee dataset.

This repository is built incrementally using test-driven development. Backend and frontend live in separate npm workspaces.

## Project Layout

- `backend` - Express, TypeScript, Prisma, SQLite, Jest, Supertest, Zod
- `frontend` - React, Vite, TypeScript, TanStack Query, Material UI, React Hook Form, Zod, Vitest
